Loading · splash + แถบ progress · mock-up รอบ 2 (ตกลงแล้ว 2026-11-15)

ปัญหา: เปิดแอปครั้งแรก (หรือตอน server เพิ่งตื่น) จอว่างจนรู้สึกว่าค้าง. ข้อเสนอ: Splash ใน index.html ขึ้นทันทีจนหน้าแรกพร้อม + แถบ progress บาง ๆ ที่ขอบบนสุด สำหรับงานที่รอ server หลังแอปขึ้นแล้ว (sync, หน้าที่ยังไม่เคยโหลด). ข้อมูลในเครื่องยังขึ้นทันทีเหมือนเดิม ไม่มี spinner สำหรับการอ่านในเครื่อง (DESIGN.md §6 Loading). แถบและ splash ในภาพนี้เคลื่อนไหวจริง.

ลำดับเวลาเมื่อเปิดแอป

  • 0 s splash (โลโก้ + ชื่อ) ขึ้นพร้อมหน้า HTML
  • เกิน 1 s แถบใต้ชื่อ + ข้อความว่ากำลังรออะไร
  • เกิน 10 s "ใช้เวลานานกว่าปกติ" + ลองใหม่
  • หน้าแรกพร้อม splash จางออก (150ms) แล้วถ้ายัง sync อยู่ ต่อด้วยแถบขอบบน

คำถามให้เลือก

  • Q1 สไตล์แถบขอบบน: A วิ่งวน / B ค่อย ๆ เติม (ภาพ 8)
  • Q2 แถบตอน sync เบื้องหลัง: เฉพาะรอบแรกหลังเปิดแอปและตอนกด sync เอง (แนะนำ) / ทุกรอบ / ไม่แสดง (มีไอคอนที่หัวอยู่แล้ว)
  • Q3 เครื่องใหม่: บอกจำนวนรายการที่ได้รับ (ภาพ 5) / ข้อความอย่างเดียว
  • Q4 Splash: บอกช่วงที่รอ (ภาพ 3) / แค่แถบ ไม่มีข้อความ
